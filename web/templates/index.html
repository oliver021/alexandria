A registry for AI agents

A versioned library of skills and grounding.

Alexandria stores packages that agents read over MCP and people browse on the web. A skill tells an agent how to do something. A grounding package gives it facts to rely on. Every version is an immutable zip with a single entry point.

Two kinds of entry

{{ kind_badge("skill") }}

Skills are procedural

Instructions an agent follows to get something done, together with the scripts and templates they rely on. The entry point is SKILL.md.

Browse skills {{ icon("arrow") }}

{{ kind_badge("grounding") }}

Grounding is referential

Material an agent can trust instead of guessing: specifications, tables, schemas, even SQLite databases. The entry point is INDEX.md.

Browse grounding {{ icon("arrow") }}

  • One zip, one entry point

    The entry point opens with a YAML header (name, description, version, tags) followed by Markdown. The rest of the package is free-form. Alexandria stores the zip untouched and never runs anything inside it.

  • Immutable versions

    A version moves from draft to published to deprecated and never changes. latest always resolves to the highest published semantic version.

  • Verifiable downloads

    Every package has a SHA-256 you can check after downloading, and every file in it is listed with its own hash and size.

Connect an agent over MCP

Use it over HTTP

The same catalog is available as a JSON API, documented in the API reference. Versions accept an exact number or latest.

The alx command line client wraps these calls. It searches the catalog, downloads a package, verifies its SHA-256 and extracts it safely into a directory.
